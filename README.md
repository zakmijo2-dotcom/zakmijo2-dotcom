### 🚀 About Me

Systems engineer and developer specialized in **on-device AI**, **terminal-first tooling**, and **high-performance mobile architectures**. Focused on local-first LLM inference on edge devices, sandboxed agent runtimes, and low-latency native apps.

- 🧠 **On-Device LLM & NLP:** Fine-tuning and running quantized edge models (Tamazight LLM, Qwen2.5 on Termux/Android).
- ⚡ **Autonomous Agents & Tooling:** Building hardened, sandboxed agent runtimes, model proxies, and multi-provider harnesses (`Mijoz`, `Hermmers`, `Nova`).
- 📱 **Mobile Systems:** Native Android with Kotlin & Jetpack Compose, plus high-performance Capacitor 7 hybrid WebGL architectures (`Open Historia`, `Mijo-m3u`).
- 🛠️ **Open Source:** Contributor to large-scale alternate history simulation, terminal environments, and developer tools.
